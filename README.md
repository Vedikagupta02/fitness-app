# Fitness Hub 

A modern, minimal, and clean web application for tracking your daily physical activities and calorie intake. 

## Features

- **Movement Tracker (Green Theme)**: Log your exercises, workouts, or any physical activities along with their duration. All entries are displayed in an easy-to-read list, sorted with the newest entries at the top.
- **Calorie Tracker (Orange Theme)**: Keep an eye on your nutrition by logging foods and drinks. The app automatically calculates and displays your total caloric intake for the session.
- **Clean UI**: Built with a beautiful, responsive, and fully centered UI using modern web design principles and Tailwind CSS.

## Tech Stack

- **HTML5**: Semantic structure for multiple pages (`index.html`, `movement.html`, `calorie.html`).
- **JavaScript (Vanilla)**: DOM manipulation, event handling, and dynamic UI updates (`movement.js`, `calorie.js`).
- **Tailwind CSS**: Utility-first CSS framework for rapid UI styling (loaded via CDN).
- **Google Fonts**: Uses the `Inter` font family for clean typography.

## Getting Started

Since this is a client-side vanilla JavaScript app, there are no build steps or dependencies to install!

1. Clone the repository:
   ```bash
   git clone https://github.com/Vedikagupta02/fitness-app.git
   ```
2. Open the project folder.
3. Double-click on `index.html` to open it in your web browser.
4. Start tracking your fitness journey!

## Application Structure

- `index.html`: The main landing page / hub.
- `movement.html` & `movement.js`: The frontend and logic for the Movement Tracker.
- `calorie.html` & `calorie.js`: The frontend and logic for the Calorie Tracker.

## Customization

The project uses Tailwind CSS via CDN. You can easily adjust the color palette, sizing, and shadows by modifying the Tailwind utility classes directly inside the `.html` files.
